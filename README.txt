IKEMEN GO GitHub Incremental Updater
====================================

WHAT THIS DOES
--------------
Players launch "Update-and-Play.bat" instead of launching IKEMEN_GO.exe directly.

The updater checks for mismatches between the repo main branch and your build on your machine. If there is a mismatch, ( character file, stages, etc, ), the updater will automatically download the missing/changed files without making you have to redownload the entire build. 

DO NOT change anything in any files for this whatsoever, as it can result in it breaking on your end. If you have any questions, ask me in the cord.
