==============================MOVELIST================================

Basic Commands:

F - Foward
B - Backward
D - Down
U - Up

x = LP - light punch
y = SP - strong punch
z = SA - special attack
a = LK - light kick
b = SK - strong kick
c = unnused button ( Can use for your preference )

Dash - F, F or B, B or F, LP + SP or B, LP + SP 

Super Jump: D, U or LK + SK

Advancing Guard: LP + SP  in Guard

Wall Jump: F (Near wall)


Unique moves:

Brutal Claw - F + SP

Cross Slash - SP, LP ( Air Ok )

Sliding Claw - DF + SP

Drill Claw - Any direction + LK + SP ( Air OK )


Special moves:

*Can use special EX using 2 buttons and 500 powerbar

Berserker Barrage - D,DF, F + punch 

Tornado Claw - F,D, DF + punch

Berserker Slash- D, DB, B + punch

Diving Kick - D, DF, F + kick (Air Only)

Berserker Rage - F, D, B + kick


Super moves:

Berserker Barrage X: D, DF, F + SA 

Fatal Claw: D, DB, B + SA ( Air OK )
	
Weapon X: F, D, DF + SA (Climax)
