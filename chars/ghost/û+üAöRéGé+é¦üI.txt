仮面ライダーゴースト	2020/11/01
出典「仮面ライダーゴースト」

  コントロール（動き）
  --------

    Basic Controls
    --------------
　　　仮面ライダーゴーストは3ボタンのキャラです。
　　　abcがそれぞれ、攻撃に対応しています。

      D - 下
      F - 前
      U - 上
      B - 後
      x - 闘魂発動
      y - 
      z - 
      a - 弱攻撃
      b - 中攻撃
　　　c - 強攻撃


    通常の動き
    -----------------
      U              - ジャンプ
      UF             - 前ジャンプ
      F              - 前移動
      DF             - 屈み
      D              - 屈み
      DB             - 屈みかガード
      B              - 後移動かガード
      UB             - 後ジャンプ
      F, F           - 前ダッシュ
      B, B           - 後ダッシュ（バックステップ）
      ab             - リカバー
      bc             - 喰らい抜け（2ゲージ消費）

    投げ
    ------　
      F/B + c 　　　 - 投げ

    必殺技
    ---------------

      D, F + a       - ロビン魂(空中可)
      D, F + b       - エジソン魂
      D, F + c       - ビリー魂

      D, B + a       - ナギナタスラッシュ
      D, B + b       - ムサシ魂
      D, B + c       - ベンケイ魂

      D, D + a       - ニュートン魂(引力)
      D, D + b       - ニュートン魂(斥力)　※コンボ中1度のみ使用可能

   ◎闘魂発動後開放
      F, D, DF + b   - リョウマ魂


    超必殺技
    ------------- 　
    　D, F, D, F + a - 　Lv.1 オメガドライブ
    　D, B, D, B + a - 　Lv.1 マシンゴーストライカー
           x         -   Lv.1 闘魂発動（画面下部に闘魂ブーストアイコン表示時）

    　D, F, D, F + b - 　Lv.2 グレイトフルオメガドライブ

    　D, F, D, F + c - 　Lv.3 ムゲンゴッドオメガドライブ
